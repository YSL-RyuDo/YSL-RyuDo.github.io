주요 개발

CodeName VAIS C++ · Windows IOCP · C# · Unity

IOCP 서버의 세션·패킷 처리부터 Unity의 경기·프로필·상점 연동, 재접속 시 표시 상태 복원까지 작업했습니다. ReconnectJournal에는 지속 상태를 보관하고 피해·보상·플레이어 명령 재실행은 제외했습니다.
