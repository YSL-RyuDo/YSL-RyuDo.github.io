# Young-Sang Lee — Portfolio

[English](README.md) · [Korean](README.ko.md) · [Japanese](README.ja.md)

게임 서버 개발, 근거가 있는 팀 기여와 연구를 소개하는 개인 포트폴리오입니다.

영어가 기본이며 `/ko/`·`/ja/`에서 전체 번역을 제공합니다. `/en/`은 영어 첫 페이지와 같습니다. 정적 HTML·CSS 사이트라 빌드 단계가 필요하지 않습니다.

주요 개발은 Project Vector(비공개·개발 중), BNB/BnBServer, DeathGuider 기여 포크입니다. GCTLAB은 저장소 수정 없이 간략히만 언급합니다. WISA 2026·CISC-W 2025·MOD 출처 연구는 별개 항목입니다.

정적 HTTP 서버로 저장소를 열어 언어별 경로, 키보드 포커스, 모바일 화면과 공개 프로젝트 링크를 점검하세요. 소스 공개 범위와 팀 크레딧을 유지합니다. 기존 사이트 에셋과 프로젝트 페이지는 보존합니다.
