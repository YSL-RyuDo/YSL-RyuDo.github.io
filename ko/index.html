현재 개발 중 · 소스 비공개

Project Vector

팀 멀티플레이 FPS의 C++ Windows 서버와 Unity 클라이언트 연동을 작업하고 있습니다.

C++IOCPC#Unity

내 기여

  • IOCP 연결 처리, 세션과 패킷 디스패치.
  • 경기 수명주기·재접속 상태, 프로필·커리어·상점 연동.
  • 게임플레이 네트워크, 스킬 연동과 클라이언트 검증 도구.

개발 진행 중입니다. 현재 검사는 상용 수용량을 입증하지 않으며, 두 클라이언트 경기와 두 PC 음성 검증은 별도 과제입니다.

멀티플레이 · 공개 소스

BNB / BnBServer

멀티플레이 게임을 개발하며 생긴 질문, ‘게임 안의 가격은 어떻게 정해야 할까?’가 가격정책 연구로 이어졌습니다.

C++C#UnityTCP

내 기여

  • 클라이언트·서버 패킷 흐름, 방과 경기 연동.
  • 보상·플레이어 데이터·상점 관련 흐름.
  • CISC-W 2025 포스터 연구의 가격정책 시뮬레이션.

팀 클라이언트 작업과 서버 담당을 구분합니다. 가격 연구는 시뮬레이션이며 실제 서비스 매출 증가를 주장하지 않습니다.
