## サイト構成

`/en/`、`/ko/`、`/ja/`：各言語の完全版。

`/<言語>/work/<プロジェクト>/`：9件の開発事例。

`/<言語>/research/<研究>/`：3件の研究紹介。

`/<言語>/resume/`：印刷・PDF保存用スタイル付き履歴書。

`assets/`：共通スタイル、本人写真、既存のプロジェクト画面。

## プレビュー

リポジトリのルートから静的HTTPサーバーで実行します。依存関係のインストールやビルドは不要です。トップ・詳細ページの言語切替、動画リンク、キーボード操作、狭い画面を確認してください。印刷ボタンはブラウザーの印刷・PDF保存を使用します。

## 内容の管理

日付、担当範囲、検証範囲は3言語を併せて更新してください。チームと素材制作者のクレジットを維持し、非公開ソース、アカウントデータ、署名鍵、学籍番号を公開しないでください。トップページ更新時も既存の詳細ページを保持します。

## ソースへのアクセス

各プロジェクトからリポジトリと記録済みの担当根拠に直接アクセスできます。トップはVAIS・Arcana Duel・Slap Squadを中心に構成し、VAISには再接続状態の復元解説を用意しています。動画は自動再生されません。
