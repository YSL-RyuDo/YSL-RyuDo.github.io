# Young-Sang Lee — Portfolio

[English](README.md) · [Korean](README.ko.md) · [Japanese](README.ja.md)

ゲームサーバー開発、根拠のあるチーム担当範囲、研究を紹介する個人ポートフォリオです。

英語がデフォルトで、`/ko/`・`/ja/`に完全な翻訳を用意しています。`/en/`は英語トップと同じです。静的HTML・CSSのためビルド工程はありません。

主な開発はProject Vector（非公開・開発中）、BNB/BnBServer、DeathGuiderの担当記録フォークです。GCTLABはリポジトリを変更せず概要だけ掲載しています。WISA 2026・CISC-W 2025・MOD出所研究は別項目です。

静的HTTPサーバーで開き、各言語パス、キーボードフォーカス、モバイル画面、公開リンクを確認してください。ソースの公開範囲とチームクレジットを維持し、既存の素材・プロジェクトページを保存しています。
