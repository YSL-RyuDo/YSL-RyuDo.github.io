이종 게임 MOD 패키지의 서버 기반 다중 출처 복원

코드, 이미지 특징과 다중 부모 선택을 이용한 MOD 패키지 출처 복원입니다. 알고리즘과 실험 범위, 한계를 기록하며 확장하고 있습니다.

Java opcode SimHash, 이미지 해시와 구조화 자원 특징으로 등록된 출처 후보를 검색하고, 구성 요소를 여러 출처 또는 UNKNOWN에 할당합니다. Phase 6~7 동결 기준은 후속 확장과 구분해 보존합니다. 의존 그래프 보정의 주요 TEST 지표 효과는 작고 통계적으로 확정되지 않았습니다. 사람의 검토를 돕는 기술적 출처 근거이며 법적인 소유권 판정은 아닙니다.
